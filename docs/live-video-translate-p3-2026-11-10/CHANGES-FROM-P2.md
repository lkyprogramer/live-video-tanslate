# 相对上一轮 P2 包的变化

旧包日期2026-11-07、代码基点7121c1b；新包日期2026-11-10、基点77e24c3。不是把旧候选换一个名字继续跑。

1. **改正代码完成度。** P2 freeze、score、B0 replay、B1/B2适配器、B3真原生流和B4筛选已有实现；旧包“P2 CLI待实现”不再有效。P3只补候选在线完整链路和新模型适配。
2. **继承失败。** PLaMo、SenseVoice、whisper-ja760、Vox960、Gemma官方AST等保留实际失败记录；Gemma中文only只失败G0，正式34项NOT_RUN，不给假分数。
3. **更换主假设。** 普通离线模型换框架不再是主矩阵。优先R2T2的稳定前缀后训练，以及123M日语声学cache-aware RNNT；两者均有部署门槛，不预设Mac可用。
4. **限定状态策略。** R2T2正式主配置固定160/U1、full llama、S0、no_reset W16O8；不让实施者事后在无限累积、每VAD重置、滚窗之间任选最优。日语123M先480ms/RNNT，CTC不得冒充同一模型路线成功。
5. **把中文时效单独拆开。** S0检验识别和资源；S1只作为条件消融，让稳定完整日文句提前进现有Hy。日文更早不等于中文更早。
6. **缩小搜索预算。** 3主配置+1条件配置、最多2 E2E；新模型不逐个无限补测。备选Omni/FunMLT/Kana择一，wllama部署迁移暂不占席位。
7. **分清内存探索与正式R。** P3新增research_R_memory用于低占用研究，但不能替换P2冻结的正式R延迟主指标或直接更换默认。
8. **补执行防误用。** 已实现命令/包内helper/待开发接口明确分开，未知锁保持null，模型已清理意味着必须恢复选中资产；取消要等真实worker退出，不以asyncio取消假充完成。
9. **带检索与审计证据。** 45查询/395命中/311精确URL只是覆盖量；新包包含底稿、来源入口和66份源码blob核对摘要。没有把所有命中都称“全文精读”。

上一轮历史分数和冻结收据继续有效；新包只替换下一步工作建议，不覆盖旧证据。不从小型脚本测试推导新模型在M1的收益。
