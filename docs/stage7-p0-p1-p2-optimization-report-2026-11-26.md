# Stage 7：《重启人生》EP01 P0+P1+P2 优化落地与对比实测报告（2026-11-26）

> **核心结论**：按 [Stage 6 全集验收报告](stage6-ep01-full-episode-verification-report-2026-11-26.md) 确定的 P0/P1/P2 优先级完成落地后，在《重启人生》EP01 上实测验证：
> - **P0 全集 ASR 识别率大幅提升且零 ANE 延迟失控**：全集 45 分钟（`0–44:50`）ASR CER 从 `0.4549` 降至 **`0.3702`**（**-8.47 个百分点**，多找回 **`+1,469`** 个日语有效字符，`15–30m` 段降至 **`0.3238`**）；`947/947` 切片全部运行在 ANE（`0` 回退），原生混合解码 ASR **P50 `39.70 ms` / P95 `160.28 ms`**。
> - **P1 纯标点空转清零、草稿重度跳变显著下降**：全集跳过 `33` 条纯标点切片（`5m` 实时回放拦截 `2/2` 条 `"。"`，`0` 条纯标点传入 GPU MT 或触发告警）；`5m` 1× 实时回放中，首版草稿相对终稿重度改写率（`>= 0.7`）从 Stage 6 的 `47.04%` 降至 **`31.07%`**（`-15.97` pts），首版草稿编辑比中位数从 `0.6667` 降至 **`0.5000`**。
> - **P2 滑动 4 轮上下文与日剧提示词稳中有升，同时暴露 `Qwen3-4B` 参数量天花板**：654 句全集 Arm B Oracle-ASR `chrF` 提升至 **`0.2019`**（全文 `0.3163`，均高于 Stage 6 的 `0.1974` / `0.3083`）且维持 `0` 假名泄漏；`5m` 1× 实时回放 `chrF` 从 `0.1920` 升至 **`0.2028`**（同窗 ASR CER `0.4667 -> 0.3725`）；但 18 条 `E3/E4` 疑难句对照显示，`Qwen3-4B`（`4-bit`）对传呼机 `ポケベル`、自动铅笔 `シャーペン`、茶杯 `湯飲み` 等词典常识与复杂受益语态仍存在小模型认知上限。

## 1. 本轮改动清单（P0 + P1 + P2）

1. **P0 原生 ANE 自适应混合解码与短窗精细切分**：
   - [nemo_ane.mm](../engine/native/nemo_ane.mm)：为 `RnntDecoder` 增加复用式 `PredScratch` 消除逐步堆分配，并新增 `use_beam == 2`（`hybrid`）模式——先以极快 AMX `greedy` 解码，仅当音频 `>= 1.5s` 且有效日文字符密度 `< 3.0 chars/s` 时，**直接复用同一次 ANE 编码器输出 `enc_proj`** 就地运行 `decode_beam` 并在字符数更多时采用（零额外 ANE 前向调用）。
   - [profiles.toml](../engine/config/profiles.toml) / [profiles.example.toml](../engine/config/profiles.example.toml) / [config.py](../engine/src/subtitle_service/config.py)：`AsrConfig.decoding` 支持 `"hybrid"`，`MtConfig.context_turns` 上限放宽至 `8`；`m1-pro-nemo` 主配置调优为 `decoding="hybrid"`, `vad_pause_ms=180`, `max_segment_s=2.8`, `pad_ms=500`, `context_turns=4`。
   - [local_pipeline.py](../engine/src/subtitle_service/local_pipeline.py)：新增 `_guard_final_against_draft`（Draft->Final 字符塌缩 `< 55%` 时自动重试 `beam` 或保留/拼接被吞前置从句），并将 Draft ASR 左侧填充从 `150ms` 提升至 `350ms`。
2. **P1 纯标点前截断与严格日语 SOV 草稿门控**：
   - 识别结果仅含标点/空白（`_has_meaningful_ja == False`）在 `LocalSession` 调度入队前直接拦截，不送入 `Qwen3Translator`（`asr_end` 记录 `mt_skipped="punct_only"`）。
   - 从 `_DRAFT_CLAUSE_END` 剔除日语谓语前常反转的高风险助词（`"は"`, `"が"`, `"も"`, `"て"`），提高 `_should_emit_draft_ja` 门槛（最小 `8` 字、增量 `+5` 字、前缀一致性校验）与最小开口时长 `max(1.6, draft_interval_s)`。
3. **P2 滑动多轮 KV 上下文与通用口语/日剧提示词**：
   - 升级 `Qwen3Translator.SYSTEM_PROMPT`（通用日剧口语、外来片假名实义、分数比例、`〜ちゃん` 称谓、引号转述与受益语态规则，零 EP01 特化词表）。
   - 重构 `_Qwen3Session` 滑动多轮 KV Cache：取消每 2 轮粗暴清空与 5s 静音清空，改为保留最近 `history`（上限 `context_turns=4`，满载或超 420 tokens 时回放保留最近半数对话轮次，静音间隔阈值放宽至 `12.0s`），并经 `apply_chat_template` 逐字符一致性断言通过。

## 3. 回归验证状态与下一步判断

- **单测全量通过**：`PYTHONPATH=.:engine/src engine/.venv/bin/pytest engine/tests p0/p2/tests p0/local_streaming` -> **`98 passed in 5.55s`**（0 failed, 0 skipped），覆盖新增 ANE `hybrid` 模式、Draft->Final 塌缩守卫、`punct_only` pre-MT 跳过、SOV 草稿门控与 4 轮滑动窗口回放。
- **下一步核心取舍**：
  1. 若希望将全集 `CER 0.3702` 进一步下探至 `< 0.25`，核心瓶颈已明确在 **FastConformer 前端全局均值方差归一化与 619M 单体短句识别率**（Oracle SRT 下最佳也仅 `0.2603`），而非 ANE/Metal 算力。
  2. 若希望根治 `ポケベル / シャーペン / 30分の1 / 湯飲み / 運んでもらえて` 等翻译常识与语态错误，建议下一阶段在 Arm B 基准上评估更换更高容量或日译中专项量化翻译模型（`7B/8B 4-bit` 或专项日译中模型），并衡量其与 45 分钟延迟预算（`< 600ms` MT P95）的权衡。
