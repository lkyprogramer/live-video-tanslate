## 1. 核心结论（先给答案）

1. **看清了 MLX 链路的真实时间分布**：
   - **`Qwen3-ASR-1.7B-8bit`**（P50 `394.7ms`，总计 `38.54s`）：**95%+ 的时间花在 `audio_enc`（`51.8ms`）+ `prefill TTFT`（`132.9ms`）+ `decode`（`197.5ms`）**；`preprocess_1 + embed_merge + clear_cache + dup_preprocess_2` 合计仅占 `~16.2ms`（`~4%`）。
   - **`Qwen3-4B-Instruct-2507-4bit`**（P50 `569.6ms`，总计 `56.06s`）：**`prefill TTFT`（`396.0ms`）占了整整 `70%` 耗时**，而 decode 仅占 `177.2ms`！
2. **MLX 底层提速微基准结果（单句计算总耗时直降 `32.77%`）**：
   - **ASR 胜出方案 `A3`**（去重复预处理 + O(1) `mx.concatenate` + 去 `clear_cache` + `cache_limit=1GiB`）：总耗时 `38.86s → 37.58s`（`-3.28%`，`RTF 0.0897`），D0 CER 反降 `0.2185 → 0.2154`（`90/91` 与 A0 逐字一致）；纯 MLX Mel (`A4`) 仅多省 `2.7ms` 但将 `wmf-04` CER 轻微拉高至 `0.1829`，**不采用 `A4`**。
   - **MT 胜出方案 `M1`（固定 `SYSTEM_PROMPT` KV Cache 复用）**：**提速 `42.07%`**（总计 `56.06s → 32.47s`，**`TTFT 396.0ms → 150.5ms`**，**`P50 569.6ms → 324.6ms`**，`P95 972.2ms → 640.9ms`），Pass 1 与 Pass 2 结果完全一致（零 KV 污染）；`72/91` 与 M0 逐字完全相同，其余 19 条为同义汉语措辞微调（如 `"做个复习"` vs `"进行一下复习"`）。
   - **MT `M3` 投机解码（`Qwen3-0.6B-4bit` draft）淘汰**：draft 接受率仅 `33.44%`，反而**慢了 `61.92%`**（`P50 0.916s`），已淘汰并删除临时权重。
   - **联合交替运行（`A3 + M1` vs `A0 + M0`）**：总计算耗时从 `106.45s` 降至 `71.57s`（**`-32.77%`**，`P50 1.094s → 0.728s`，`P95 1.884s → 1.528s`）。
3. **重磅突破：`speech.cpp` (NeMo-v2 619M GGUF) 实测表现远超预期**：
   - **纯 CPU 8 线程（`q8_cpu_t8_beam`）**：**`P50 = 222.9ms`（`RTF = 0.055`，~18× 实时）**、RSS 仅 `894 MiB`、**`0` GPU 占用**！D0 CER **`0.2100`**、D1 CER **`0.3443`**（均优于 `Qwen3-ASR-1.7B` 的 `0.2154 / 0.3683`，且完整抓出 `1回キレられたんだよなれなれしいっつって`）。
   - **Metal GPU（`f16_gpu_beam` / `q8_gpu_beam`）**：`P50 = 125.8ms / 116.7ms`（`RTF = 0.0285 / 0.0267`），D0 CER **`0.2054 / 0.2100`**、D1 CER `0.3533 / 0.3503`（`greedy` 模式更快达 **`64.4ms` / `RTF 0.0149`**，且 10s 静音输出为空 `""`）。
   - **并发争用实测结论**：
     - **异构并行（`CPU NeMo-v2` + `GPU MLX Qwen3-4B`）**：MT 延迟几乎零膨胀（`0.306s → 0.318s`，**仅 `+3.79%`**），ASR 零退化；
     - **双 Metal 并行（`ggml-metal NeMo-v2` + `GPU MLX Qwen3-4B`）**：MT 延迟膨胀 **`+33.75%`**（`0.306s → 0.410s`），证实了双 Metal 上下文争用。

## 4. 对下一步 Layer 1–4 落地的直接工程决策

1. **立刻落地 Layer 1 + Layer 2（`Qwen3-ASR A3` + `Qwen3-4B M1 KV Cache` + 异步解耦 + 可中断优先调度）**：
   - 纯计算 P50 已实测压至 **`0.728s`**（`-32.77%`），可无损合入 `m1-pro-hq` 并彻底消除 `seek` 撞 `busy` 和队列 `overloaded`。
2. **NeMo-v2 619M 具备极高实用价值，推荐走“CPU 异构并行”或“纯 MLX 移植”两条高确定性路线**：
   - `q8_cpu_t8_beam` 跑在 CPU 上仅需 **`223ms` P50、`894 MiB` RSS、`+3.79%` MT 并发膨胀**，速度已是 `Qwen3-ASR` 的 **1.8×** 且 D0/D1 CER 更优，**无需承担双 Metal 争用即可上线成新一代高速高精异构档**（`CPU NeMo-v2` + `GPU MLX Qwen3-4B`）！
3. **同步推进 Layer 3（能量谷/VAD 谷 `3.5–4.5s` 短切分 + 重叠去重 + 双行自适应字幕 UI）**：
   - 计算耗时已压到 `0.5~0.7s` 量级，当前观众体感延迟的**绝对大头只剩“等待 15~20s 整段说完才切分”与“单槽 4s 硬清除”**；下一阶段应把主战场全面转向 Layer 1 + Layer 3 全栈改造与 Chrome 真实端到端验收。
