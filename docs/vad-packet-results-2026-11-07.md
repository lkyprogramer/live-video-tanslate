# Silero v6.2 原整包调用补测结果

2026-11-07，M1 Pro、32GiB。**补测未过线，保持现行ReazonSpeech + Silero v4 + Hy-MT2。** 两轮候选即使采用宽松判定，仍各少于同轮基线3项，并出现新增关键误译，因此未进入E6原速验证。

## 变量与输入

只替换VAD权重。两组均按原3200samples、200ms整包调用 `accept_waveform`，最后一包可短，原生Flush，不加FIFO，不补尾。采样率16kHz、threshold0.5、最短语音150ms、静音等待600ms、max_speech4s、Reazon INT8／2线程及M0保持一致。Silero v6.2固定提交为 `be95df9152c0d7618fa1edfeb296fc3dae32376f`，沿用同一sherpa2.0.1。

9段连续PCM共476.058s，逐样本核对切片来源。VAD与ASR覆盖9段；MT沿用原34项开发集的3段主评分素材，v4两轮各62次，v6.2各53次。独立短句与配乐的原始ASR保留用于观察，未将它们宣称为新的端到端中文验收。人工复听暂缓，`test/`未访问。

当前程序与模型、输入、提示词、种子和运行时均已保存哈希／设置；控制组88条日文及两轮各62条中文全部逐字复现冻结记录。相同范围和日文沿用原MT种子索引，新范围按冻结哈希规则派生，避免新段号平移后续输入的种子。

所有语义判定为 `ai_reviewed`，没有新增人工核准。区间下限为保守命中，上限将所有边缘项计入，不是统计置信区间。方向遗漏、Enforcing错拼与概要缺失、委员会重点关系及种子11条款采纳对象列入敏感性。沿用冻结主表对 `158-160` 的橙色中下方与决策核心的匹配；该项两组都有额外错误词，对称剔除时控制为19／17，候选为12–16／11–14，结论不变。

两轮都恢复了“名字和一句话”；种子11也恢复了语言、副语言和非语言三类信息。但候选失去了未知人物、烹饪研究者／眼镜／短发、委员招募确定和幻灯片切换等必要内容。开头“我打开看看”仍只得到“是”。片段减少不等于语义改善。

已确认的新增关键文本错误包括：

- 种子11把正文之外的附录和定义两个事项译成“添加附录，也就是定义”。
- 两轮日文输入均正确写出「憲章」，MT却译成“宪法”。
- 种子29的日文保留「私にも発言権があるのか」，中文改成肯定的“我也有发言权”。

照片句的VAD逻辑放行推迟1.6s，只表示按PCM包时钟可计算的确认等待变化，不是实测WS到达延迟。ASR调用P95从0.150s变为0.185s；M0调用P95控制为0.416／0.413s，候选为0.427／0.430s。两组分段和MT输入量不同，这些离线调用时间不能代替首条正确中文或句末到中文的原速P95。
